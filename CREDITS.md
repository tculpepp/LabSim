# LabSim Credits

**Game design:** our 8-year-old lead designer, who invented the lab, the
experiments, Tom, Gizmo, the slimes, and the animals.

**Code and art:** written for LabSim. All characters, rooms, items, and
effects are drawn in code with vector shapes. There are no image files.

**Sound:** every sound effect is synthesized in code (`internal/sfx`).
There are no audio files.
